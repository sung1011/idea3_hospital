# 格子医院 · 分阶段落地

对照 [main.md](main.md)、[events.md](events.md)、[week.md](week.md)。

技术：Vue 3 + TypeScript。`src/sim/` 纯逻辑，`src/ui/` 只读状态、发操作。Tick、离线结算、周赛对手共用同一套 `tick()`。

每档先写 `sim` 和测试，再挂一层薄 UI。结束时必须能打开页面玩。

后做（不挡手感）：真人对手快照、内购位、Canvas / 骨骼、微信小游戏适配。

---

## 0. 脚手架

- [x] Vite + Vue 3 + TypeScript + Pinia + Vitest
- [x] 目录：`src/sim/`、`src/ui/`
- [x] 空 5x5、正门（底边外侧、正对第 3 列）、钱 / 口碑条、时钟每秒 `tick()`

过关：空地板、正门、顶栏数字、T+ 在走。

---

## 1. 感冒产线

只做一条路：前台 → 诊断 → 治疗 → 药房。

- [x] 类型和常量表（房间、病种、开局 5000 / 50）
- [x] 建造 / 占地 / 前台必须贴正门
- [x] 选「队列未满且最近」的下一房
- [x] 走路（曼哈顿 × 2 秒 × 护士系数）
- [x] 进队、吞吐进度条、出队、出院给钱 + 口碑
- [x] 进场间隔、场上最多 20 人
- [x] UI：点类型再点空地建造；格子显示房名和队列人数；病人点在格上移动

过关：摆齐四房，挂上医生，人走完出院、钱在涨。缺房或队列满时人先停住（不要走人）。

不做：骨折、污染、事件卡、卖房。

---

## 2. 堵的手感

- [x] 排队 +4 / 走路 +2（每 10 秒）
- [x] 怒气 80 且下一家满 → 走人；100 → 立刻走人
- [x] 排队每 30 秒病情 +1；到 3 还没进治疗 → 死亡
- [x] 走人 -2 口碑，死亡 -5 口碑
- [x] 格子能看出队列长度和怒气
- [x] 口碑到 0 停进场

过关：故意少建一间治疗室，能看着队爆、走人、钱停。

---

## 3. 员工三条数

- [x] 医生绑房，空槽吞吐为 0
- [x] 护士改走路时间
- [x] 招募 / 解雇
- [x] UI：点房间派医生、顶栏招护士
- [x] 保洁只留数据和按钮，清洁效果跟第 4 档一起做

过关：前台没医生 = 关门；招第二个护士，人走得明显更快。

---

## 4. 污染 + 候诊厅 + 重铺

- [x] 污染降吞吐、邻格扩散、≥70 改写成传染病
- [x] 保洁每 5 秒 -8，没有自动消退
- [x] 候诊厅：下一家满则溢入，有空位按等待最长出箱
- [x] 卖房：退费、队内怒气 +20、改走最近同类型，没有则走人
- [x] 升级先做「队列 +2」

过关：脏了会慢、会传；候诊厅能少走人；卖掉重摆当天能再开张。

## 6. 事件卡

对照 [events.md](events.md)。

- [x] 90–150 秒弹一张，左右选择
- [x] 持续效果最多 3 分钟
- [x] 先做 6 张
- [x] 弹层盖在棋盘上，点完立刻回产线

过关：卡会改权重 / 污染 / 临时吞吐，点完产线还在转。不要做成牌组。

## 7. 挂机

过关：关页等一分钟再开，摘要对得上，布局差会亏。

## 8. 急诊口

- [ ] 只改门，不占格
- [ ] 解锁后开关
- [ ] 约 25% 标急诊，跳过前台和诊断，插队，成功率 ×0.85

过关：一开急诊，治疗 / 手术队被插，日常病人更容易溢进候诊厅。
